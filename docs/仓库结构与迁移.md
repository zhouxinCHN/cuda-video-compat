# 仓库目录结构（迁移对照）

本文用于把另一台机器上的旧目录整理成相同结构。仓库按“组件 / 测试 / 文档 / 证据 / 基准 / 测试数据”分层，**不把 FFmpeg 源码、编译产物、参考 YUV 放进仓库**。

> 说明：说明性文档已统一为中文文件名；`README.md`、治理类文件和证据原始数据保留约定文件名。

## 在另一台机器上复刻

如果另一台机器已有旧目录，建议新建目录后按上表移动，不要直接删除旧文件：

```bash
OLD=/path/to/old/repo
NEW=/path/to/new/repo
mkdir -p "$NEW"

# 拷贝源码、测试、文档、测试码流
rsync -av "$OLD/cuda_shim" "$OLD/tests" "$OLD/benchmarks" \
  "$OLD/docs" "$OLD/testdata" "$OLD/scripts" "$NEW/"

# 再按上表重命名/合并文档
```

如果直接 `git clone` 当前仓库，则不需要上面的拷贝步骤，只需要按根 [README](../README.md) 准备外部 FFmpeg / ROCm / Mesa 依赖。

## 迁移后的自检

```bash
python3 scripts/check_links.py

bash -n tests/quick-verify/*.sh tests/zerocopy/*.sh
```
